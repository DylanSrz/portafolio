# Portafolio de Dylan Suarez

Sitio personal con mis proyectos, stack y contacto. Hecho con Next.js, TypeScript y Tailwind CSS.

## Cómo correrlo

```bash
npm install
npm run dev
```

El sitio queda en http://localhost:3000.

## Editar el contenido

Los proyectos están en `lib/proyectos.ts`. Cada uno genera su página en `/proyectos/<slug>`, y las capturas viven en `public/proyectos/`.

## Despliegue

Se publica en Vercel importando el repositorio. No necesita variables de entorno.
